# 蛇吃蛇对战开发计划

## 目标

在现有竖屏小游戏上增加离线电脑对手，让玩家在同一棋盘上通过走位击败其他蛇；无需账号或网络，保留抖音、微信和浏览器支持。

## 规则

- 玩家和电脑蛇同时移动，吃果实增长；撞墙、自身或其他蛇的身体出局。蛇头同时进入同一格或互换位置时双方出局。
- 玩家身体击败电脑蛇时获得分数和成长；电脑蛇出局后在安全空位重新出现。玩家出局则结束，可重开。果实不生成在蛇身上。
- 电脑蛇选择安全方向并倾向靠近果实；无法找到安全方向时继续前进。棋盘空间不足时暂缓重生。
- 保留暂停、最高分、触摸及键盘控制，界面区分玩家与电脑蛇并解释规则。

## 实施与验收

1. 在纯规则层实现同时移动、碰撞、击败奖励和安全重生；加入确定性测试覆盖关键边界。
2. 更新画面和说明，保持平台接口兼容。
3. 运行自动化测试和构建，检查可用的交互验证；记录无法真机验证的限制。
4. 提交、推送并向 main 发起合并请求，检查结果后合并。
