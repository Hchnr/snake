# 贪吃蛇 v0.0.1 开发计划

## 目标与范围

实现一个可以在手机竖屏游玩的离线贪吃蛇小游戏，优先适配抖音小游戏，并提供微信小游戏构建产物。v0.0.1 不依赖服务端、账号登录、排行榜或付费能力；两端使用各自本地存储，最高分不会跨设备或跨平台同步。

## 玩法和体验

- 开始、暂停/继续、失败后重开；滑动或屏幕方向按钮控制，禁止直接反向。
- 蛇自动前进，吃食物增长并得分；碰墙或碰到身体结束；填满棋盘时获胜。食物只生成在空格上。
- 展示当前分数和本机最高分；兼顾安全区域、不同尺寸屏幕和后台切换。浏览器预览支持键盘操作，方便开发调试。
- 抖音优先接入 Canvas、触摸、生命周期、本地缓存及用户主动触发的分享；微信提供对应的平台适配。平台接口缺失或缓存异常时游戏仍可运行。

## 技术方案

- 不引入游戏引擎和运行时第三方依赖：JavaScript + Canvas 2D，实现可测试的纯游戏规则与平台无关的界面/控制逻辑。
- 通过薄适配层接入 `tt` / `wx` API；游戏代码不依赖 DOM。浏览器预览使用单独适配器。
- 构建脚本生成 `dist/douyin`、`dist/wechat` 两套带 `game.js`、`game.json`、`project.config.json` 的独立小游戏工程，以及浏览器预览产物；构建产物可重复生成并由 Git 忽略。
- 抖音/微信 AppID 由使用者在构建时或开发者工具中配置，不写入真实凭据。平台分享、真机预览及上传需账号、AppID 和相应平台权限；本版本不声称完成平台审核或上线。

## 工作顺序

1. 写入本计划，初始化 Git 仓库，补齐 `.gitignore`、README 和基本项目脚本。
2. 实现纯游戏逻辑和边界条件，添加自动化规则测试。
3. 实现竖屏 Canvas 画面、触摸/方向按钮、生命周期、持久化和分享；优先验证抖音适配。
4. 生成并验证抖音、微信及浏览器预览包，补齐使用说明。
5. 在可用环境中执行自动化测试、构建和交互冒烟测试；记录未能由平台 IDE 或真机覆盖的验证项。

## 验收标准

- `npm test` 和 `npm run build` 在 Node.js 18+ 下成功，无需安装第三方依赖。
- 自动化测试覆盖移动、非法反向、增长计分、碰撞、尾格移动、满盘获胜、暂停/重开、持久化异常以及双平台适配/产物入口。
- 两套构建产物包含平台所需入口和配置；抖音用户可用开发者工具导入 `dist/douyin`，微信用户可导入 `dist/wechat`。真实账号导入、分享、真机和发布状态以平台实测为准。
- Git 仓库包含源码、计划、说明及忽略规则，不包含构建输出和本地平台配置。

## 补充：抖音提审基础能力

根据抖音开放平台当前文档，侧边栏复访是所有小游戏的必接能力。v0.0.1 增加支持检测、启动/回前台来源识别、用户主动跳转、从侧边栏返回后领取本机限定配色，以及异常降级和模拟测试；游戏开始前展示健康游戏忠告。奖励仅保存在本机，不依赖服务端。
